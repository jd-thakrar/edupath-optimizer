# Security Policy

## Supported Versions

The latest `main` branch is the actively supported version for security fixes.

## Reporting a Vulnerability

Please **do not** open public issues for security vulnerabilities.

Use one of these private channels:
1. GitHub Security Advisory ("Report a vulnerability" in the Security tab), or
2. A private email to project maintainers (if published in repository profile).

When reporting, include:
- Affected component/file
- Reproduction steps
- Impact assessment
- Suggested remediation (if known)

## Response Targets

- Initial acknowledgment: within **3 business days**
- Triage decision: within **7 business days**
- Fix timeline: communicated after triage based on severity

## Disclosure

After a fix is available, maintainers may publish a coordinated disclosure
summary in release notes.
